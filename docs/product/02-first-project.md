Your first project is a fictional example that belongs to your signed-in account's workspace. Choose a project name between 2 and 80 characters, such as Orbit brand refresh. Choose either Client Delivery or Campaign as the workflow.

Editing the draft does not create anything. Check every field and press Create to save the workspace and one sample project with sample tasks.

Before creation, Setup holds the draft and Preview displays the selected workflow's six sample task rows. Preview is unsaved; inspecting or filtering it does not create a project.

After creation, the sidebar uses the saved project name. Board and List are two views of that same saved project's tasks, starting with six samples. Board groups tasks into stage columns. List shows task rows and can filter by stage. Refreshing or signing in again preserves the saved project. Sample tasks are demonstration data, not real customer work.

Once the project is saved, you can add new tasks with New task, for example one called Design homepage. A new task is saved as soon as Add task succeeds. This is separate from initial workspace creation; adding a task never creates a workspace or an additional project.
